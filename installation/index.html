Installation

Install LiveContainer once, import your signing certificate, then add apps as IPAs. You need iOS / iPadOS 15 or newer (16+ for multitasking).

Before you start

Only install official open-source builds from GitHub. Keep app extensions when the installer asks (Use Main Profile / Keep All Extensions).

1. Choose a package

  • Standalone - if AltStore or SideStore is already on your device.
  • LiveContainer + SideStore - if you want both in one free app slot.

Get the IPA from the Download page.

2. Install the IPA

Standalone

Sideload with AltStore 2.2.1+ or SideStore 0.6.2+. After install, open LiveContainer Settings and tap Import Certificate from AltStore/SideStore. Export when asked, then run JIT-Less Mode Diagnose until the test passes.

Detailed standalone steps

LiveContainer + SideStore

Install with Impactor, a current iloader build, or by upgrading through an existing SideStore (keep all extensions). Then open the built-in SideStore, sign in, refresh apps, and import the certificate into LiveContainer.

Detailed LiveContainer + SideStore steps

3. Confirm signing works

  1. Open JIT-Less Mode Diagnose.
  2. Run Test JIT-Less Mode.
  3. When you see a pass result, you can add guest apps.

If checks stay red, see the FAQ and the diagnose guide.

4. Add your first app

  • Tap the plus button and pick an IPA.
  • Select which app should open next.
  • Long-press an app for settings, containers, and Home Screen shortcuts.
