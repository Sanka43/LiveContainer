App Settings

Long-press an app card and choose Settings to open per-app controls.

Data

  • Inspect the bundle folder and set a remark.
  • Choose a tweak folder: private folders are selectable; shared folders are read-only here.
  • Convert between shared and private app modes.

Container

Browse per-container options. Private apps can use Select Unused Container.

Launch and JIT

  • Launch with JIT asks LiveContainer to request JIT when starting the guest.
  • JIT Launch Script (iOS 26+) attaches a developer-provided script for chips that need it.

Privacy

Enable Lock App and optionally Hide App while locked. See the Lock App guide for stricter hiding modes.

Language

Override the guest language per app, or leave Auto to follow system settings.

Compatibility fixes

  • Fix File Picker / Fix Local Notification
  • Use LiveContainer's Bundle ID
  • Hide LiveContainer from Dyld API
  • Don't Inject TweakLoader / Don't Load TweakLoader
  • Spoof SDK Version
  • Legacy Fix File Picker (copies into Inbox; may crash or fail on folders)
  • Force Sign (re-enable signing if you previously disabled it)

Orientation

Lock orientation to landscape, portrait, or leave unlocked. Landscape locks often help older games with resolution quirks.

Statistics

View last launch time and installation date.
