Add to Home Screen

There are three ways to put a guest app on the Home Screen. Prefer Method 1 when your device and LiveContainer build support it.

Method 1: Launch App Shortcut (recommended)

Requires LiveContainer 3.6.65+ and iOS 16+. During install, keep the LaunchAppExtension and LaunchAppExtensionHelper extensions (choose Use Main Profile or Keep All Extensions).

This path launches the guest directly, skips LiveContainer's main UI, and automatically picks a free LiveContainer instance. Expect roughly one to two seconds faster than the other methods.

  1. If the app has multiple containers, long-press it and choose the container first so the launch URL targets the right data set.
  2. Long-press the app > Add to Home Screen > Save App Icon, pick a style, and save the image.
  3. From the same menu, choose Copy Launch URL.
  4. In Apple Shortcuts, create a shortcut with LiveContainer's Launch App action and paste the URL. Run it once to confirm.
  5. Share the shortcut to the Home Screen, name it, and attach the saved icon via Choose File.
  6. Duplicate the shortcut for additional apps and swap only the Launch URL.

On LiveContainer + SideStore builds you can also pin SideStore itself with the launch URL sidestore://.

Method 2: Launch URL Shortcut

Follow Method 1, but use Shortcuts' Open URLs action instead of LiveContainer's Launch App action.

Method 3: Create App Clip (deprecated)

This older path creates an App Clip icon. It is slower, leaves the clip in the app switcher, and keeps an MDM profile in Settings until you remove it manually.

  1. Long-press the app > Add to Home Screen > Create App Clip, pick an icon style, and allow the profile download.
  2. Open Settings > Profile Downloaded > Install.
  3. The icon appears on the Home Screen.
