Multiple LiveContainers

Extra LiveContainer instances (often called LC2 / LC3) let you run more guests in parallel and keep one instance free for helpers such as StikDebug.

Install another instance

  1. Open Settings > Install Another LiveContainer.
  2. Prepare LC2 or LC3; LiveContainer generates an IPA.
  3. Install that IPA with AltStore or SideStore (or save it for customization).
  4. Optional Game Mode: enable Set Category as Game and Allow Game Mode before installing.

Status indicators show a checkmark when an instance is detected and a cross when it is not.

Share apps across instances

On the primary (blue) LiveContainer, convert an app to a Shared App, then reopen gray instances to launch that shared guest.

How launches are dispatched

  • URL schemes / App Clips prefer the blue instance first, switch if that app is already running elsewhere, otherwise pick a free instance.
  • Launch App Shortcuts dispatch in the background and only open a free instance.
  • If every instance is busy, LiveContainer asks whether to open in another instance or terminate and relaunch in the first.
Missing in other instances?

Convert the app to a Shared App on the primary LiveContainer first.
