JIT Support

Configure JIT helpers under LiveContainer Settings > JIT.

Choose an enabler

  • On iOS 26+, only StikDebug or StikDebug (Another LiveContainer) are offered.
  • Use StikDebug when the helper runs outside LiveContainer; use the "Another LiveContainer" variant when StikDebug itself is installed as a guest.
  • SideStore's URL scheme is incomplete for automatic enablement - enable JIT manually for the current LiveContainer. Built-in SideStore is not supported as a JIT enabler.
  • JitStreamer-EB is deprecated. Leave the address blank for the official/default WireGuard setup; otherwise provide scheme and port (9172).
  • SideJITServer / JITStreamer 2.0 need a server address and the device UDID.

Per-app JIT

Long-press > Settings > enable Launch with JIT. On iOS 26+ with A15+/M2+ hardware, also attach a developer-supplied JIT Launch Script when the app requires one.

StikDebug in another LiveContainer

  1. Install the StikDebug IPA inside LiveContainer and complete pairing.
  2. Convert StikDebug to a Shared App.
  3. Keep another LiveContainer instance free, connect LocalDevVPN, then Run - StikDebug opens in the other instance and enables JIT for the requesting app.

Reliable enable order

  1. Do not enable JIT for LiveContainer first.
  2. Configure the enabler.
  3. Turn on Launch with JIT for the guest.
  4. Run the guest.
  5. If auto-enable fails, enable JIT for LiveContainer while the "waiting for JIT" prompt is still visible.
