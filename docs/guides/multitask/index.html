Multitask

Multitasking needs iOS / iPadOS 16.0+ and the LiveProcess app extension. Install with Keep App Extensions; otherwise you will see LiveProcess extension not found.

Start multitask

  1. Convert the guest to a Shared App.
  2. Long-press > Multitask, or enable Auto Launch in Multitask Mode so Run opens a window automatically.

Window modes (iPadOS 16.1+)

Under Settings > Multitask choose:

  • Virtual Window - floating window with dock, PiP, maximize/minimize
  • Native Window - system windows on iPadOS 16.1+

Related settings

Multitask Mode, Auto Launch in Multitask Mode, and virtual-window options such as Launch Multitask Maximized, Only One App on Stage, Auto End PiP, Skip Terminated Screen, Restart Terminated App, Bottom Window Bar, Redirect URL to Host, and Dock Width.

Container behavior

Multitask is container-aware. Opening an already-running container brings that window forward instead of spawning a duplicate. Starting a normal launch while multitask is active asks for confirmation.

JIT with multitask

When Launch with JIT is on, LiveContainer acquires JIT before opening the window. Prefer a PID-attach enabler such as StikDebug.
