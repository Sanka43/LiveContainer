Tweaks

LiveContainer injects TweakLoader into guest installs. TweakLoader brings in Ellekit (CydiaSubstrate compatibility) and then loads tweak binaries. Direct injection can still work better for some tweaks, and you may replace the TweakLoader.dylib symlink when needed.

Load order

  1. CydiaSubstrate / Ellekit
  2. Global Tweaks root folder
  3. App-specific tweak folder (recursive)

Supported formats are .dylib and .framework.

Global vs app-specific

  • Global tweaks under the root Tweaks folder apply to every guest.
  • App-specific folders apply only to selected apps.
  • Manage tweaks from the primary (blue) LiveContainer and private apps. For shared apps, convert to private, assign a folder, then convert back - assigned tweaks continue to load.
  • Assign from the Tweaks tab: create/import a folder, then pick it under the app's Settings > Tweak Folder.

Management UI

Import binaries, create folders, rename with a long-press, and delete with a swipe.

Signing

LiveContainer resigns tweaks automatically before launch when TweakInfo.plist changes or signatures look invalid/expired. You can also tap Sign on the Tweaks tab.

Related app toggles

Don't Inject TweakLoader and Don't Load TweakLoader disable tweak loading. Enabling both means no tweaks run, including TweakLoader itself.

Troubleshooting

  • One app broken: confirm the folder assignment and that TweakLoader is not disabled.
  • All apps broken: check the global folder and resign tweaks.
  • Frameworks need a valid Info.plist with CFBundleExecutable.
  • If injection still fails, try direct injection.
  • Invalid Signature errors usually clear after a manual re-sign.
