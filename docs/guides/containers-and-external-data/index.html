Containers & External Data

Containers isolate app data so you can keep multiple accounts or profiles for one guest. LiveContainer 3.2.58+ allows up to 128 containers per app (earlier builds capped at three). The same app can run in different containers across LiveContainer instances at once.

External storage caveat

Many apps crash when their data lives on external storage. If the bound folder is unavailable, that container is unavailable too.

Open container settings

Long-press the app > Settings > Container section.

Create, switch, and default

  • Create with New Data Folder and give it a display name.
  • Switch from the long-press Containers picker.
  • Open a container's detail page and choose Set Default Container so Run uses that data set.

Bind an external folder

Choose Select External Data Folder, pick a folder in the system picker, and LiveContainer binds it as a container.

Container detail actions

  • Container Name (display only) and Container Folder Name (read-only identifier)
  • Isolate App Group
  • Spoof Identifier For Vendor (stable spoofed identifierForVendor)
  • Open Data Folder
  • Unbind (list only), Delete Data, Clean Keychain, or Remove Container

Destructive actions are blocked while another LiveContainer instance is using that container.
