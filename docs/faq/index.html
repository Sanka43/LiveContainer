FAQ

Quick answers and pointers into the rest of the docs.

How do I...

  • Put an app on the Home Screen > Add to Home Screen
  • Enable JIT > JIT Support
  • Install LC2 / LC3 > Multiple LiveContainers
  • Load tweaks > Tweaks
  • Clean data, keychain, or App Group folders > Data Management
  • Keep multiple accounts > Containers & External Data
  • Open a URL inside a guest > use the link icon on the Apps tab and paste the URL, or add a share-sheet shortcut to Favorites
  • Edit container preferences > long-press > Settings > (container) > Container Preferences

Widgets, plugins, and extensions

Generally unsupported - those features need extra app IDs that LiveContainer cannot register for guests.

Fast triage checklist

  1. Update to a current stable or nightly build.
  2. Confirm AltStore/SideStore is healthy and refreshed.
  3. Sideload the same IPA directly; if it still fails, the IPA is at fault.
  4. Export crash logs from Settings > Privacy & Security > Analytics > Analytics Data.
  5. Note the LiveContainer build hash (bottom of Settings), iOS version, and device model.

Where to dig deeper

  • Install / verify / import-sign problems > Installing LiveContainer
  • JIT-less diagnose failures > JIT-Less Mode Diagnose
  • Built-in SideStore certificate errors > LiveContainer + SideStore troubleshooting
  • Crashes after launch > App Crashes
  • Odd guest behavior > Using Guest Apps
  • Per-app toggles > App Settings

Before opening a GitHub issue

  • Search existing issues and the compatibility label.
  • Include app name/version (and repo if open source), LiveContainer version plus commit hash (for example 3.1.0 c586e79), iOS version, device model, reproduction steps, and a crash report when available.
