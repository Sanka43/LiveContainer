Installing LiveContainer

Invalid entitlements

LiveContainer 3.2.58 and newer expect SideStore 0.6.2+ or AltStore 2.2.1+. Older sideloaders often produce incomplete entitlement sets.

Invalid code signature / signature wall

  1. Run JIT-Less Mode Diagnose and fix any red checks.
  2. If diagnose passes but a guest still will not launch, open that app's settings and use Force Sign.

Crash while importing an IPA

Usually means the IPA structure is invalid or the signer that produced it is incompatible. Try another export of the same app or install it directly with SideStore/AltStore to confirm the package.
