App Crashes

Version gates

  • iOS 18.2+ needs LiveContainer 3.0.0 or newer (reboot once if problems remain).
  • iOS 26.4+ needs LiveContainer 3.6.65 or newer.

Specific errors

  • mremap_encrypted() => -1 - the IPA is not decrypted.
  • main function with code 0 - IPA format is invalid (SideStore/AltStore would usually reject it too).

Still crashing?

  1. Search GitHub issues for the app name.
  2. Sideload the IPA directly; if it fails outside LiveContainer, the package is bad.
  3. Compatibility gaps for closed-source apps may have no quick fix. Open-source crashes are easier to investigate but still have no guaranteed ETA.
Official sources: Cross-check details on the official documentation and the LiveContainer repository.
