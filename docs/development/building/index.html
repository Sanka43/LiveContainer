Building from Source

Build LiveContainer on a Mac with Xcode when you want local debug builds or custom bundle IDs.

Clone the repository

Clone with submodules enabled:

git clone --recurse-submodules https://github.com/LiveContainer/LiveContainer.git
# or after a plain clone:
git submodule update --init --recursive

Expected submodules include fishhook, litehook, and OpenSSL.

Prerequisites

  • Xcode 15.4 or newer with the iOS 18 SDK (newer SDKs are fine; watch deployment targets)
  • A paid or free Apple Developer account
  • Optional Python 3 for update_json.py

Signing configuration

Edit xcconfigs/Global.xcconfig and set DEVELOPMENT_TEAM[config=Debug] (and Release if you need it). Use unique bundle IDs when you keep multiple local builds installed.

Build and run

Open LiveContainer.xcodeproj, select the LiveContainer scheme, choose a physical device, and Run.
