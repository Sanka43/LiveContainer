Standalone LiveContainer

Choose this package when you already use AltStore or SideStore and do not need SideStore bundled inside LiveContainer.

Requirements

  • iOS / iPadOS 15+
  • Multitasking needs iOS / iPadOS 16.0+
  • AltStore 2.2.1+ or SideStore 0.6.0+ to install; certificate import works best with SideStore 0.6.2+

Downloads

Get the current stable or nightly IPA from the project's official GitHub Releases. Prefer builds published by the LiveContainer project only.

Install the app

Sideload the IPA with SideStore or AltStore. After it appears on the device, configure JIT-less signing before expecting guest apps to launch.

JIT-less mode

Guest apps still need a valid signature. LiveContainer reuses the certificate (and password) exported from AltStore or SideStore so launches do not require JIT.

Note

JIT-less means JIT is not required to start an app. You can still enable JIT later for performance or compatibility - see the JIT Support guide.

Import the certificate

  1. Open LiveContainer Settings.
  2. Tap Import Certificate from AltStore/SideStore.
  3. Allow the export prompt in AltStore/SideStore. If nothing appears, keep the store app open in the background and try again.
  4. In SideStore choose Export; in AltStore set a password, then export.
  5. Open JIT-Less Mode Diagnose and run Test JIT-Less Mode.
  6. When you see JIT-Less Mode Test Passed, signing is ready.
After reinstalling the store

If you reinstall AltStore or SideStore through AltServer, import the certificate again. Skipping that step often forces a full reinstall later.

Add guest apps

  • Tap the plus control and pick an IPA.
  • Select which app should open on the next launch.
  • Long-press an app card for management actions.
