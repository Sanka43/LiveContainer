Installation

Warning

Install only official open-source LiveContainer builds. Closed third-party builds can read everything inside your containers, including secrets.

Unsupported installers

Do not install LiveContainer with Sideloadly, i4/3u Tools, NB Tool, or typical online signing services. Other tools may work by chance, but the guides on this site assume AltStore, SideStore, Impactor, or iloader as described below.

Pick a package

StandaloneLiveContainer + SideStore
What you installLiveContainer aloneLiveContainer bundled with SideStore
Free slot useOne slot for LiveContainer (plus one for your on-device sideloader)One slot covering both LiveContainer and built-in SideStore

Requirements

  • iOS / iPadOS 15 or newer
  • iOS / iPadOS 16.0+ when you need multitasking
  • For standalone installs: AltStore 2.2.1+ or SideStore 0.6.2+

Suggested sequence

  1. Choose standalone or LiveContainer + SideStore.
  2. Follow that package's install steps.
  3. Import the signing certificate so JIT-less launches work.
  4. Confirm success with JIT-Less Mode Diagnose.
Official sources: Cross-check details on the official documentation and the LiveContainer repository.
