LiveContainer + SideStore

This package embeds SideStore inside LiveContainer so you can refresh LiveContainer and other apps while using only one of the three free app slots.

Typical install paths are Impactor, iloader, or upgrading from a standalone SideStore. On Windows, install iTunes device drivers and trust the device before you begin.

Downloads

Download the LiveContainer + SideStore IPA (stable or nightly) from official GitHub Releases before choosing a method below.

Method 1: Impactor

Impactor works across platforms and can attach the increased-memory-limit and HealthKit entitlements automatically.

  1. Download Impactor (not plumesign) for your desktop OS.
  2. Add your Apple account.
  3. Drag the LiveContainer + SideStore IPA onto Impactor.
  4. Choose Only Register Main Bundle, then install.
  5. Confirm the profile under Settings > General > VPN & Device Management.
  6. Continue with Setup after installing.

Method 2: iloader

Use a current iloader build - older releases may sign LiveContainer incorrectly. Follow SideStore's own install instructions, but select LiveContainer+SideStore instead of plain SideStore when choosing what to sideload. Then finish the post-install setup below.

Method 3: Upgrade from standalone SideStore

Install the LiveContainer + SideStore IPA through your existing SideStore. Treat it as an upgrade so app data stays intact. During install, select Keep All Extensions (Use Main Profile). After the built-in SideStore works, you can remove the standalone SideStore to free a slot.

Setup after installing

  1. From LiveContainer's Apps screen, open SideStore with the top-left control.
  2. Sign in under SideStore Settings. If you migrated from a standalone store, sign out and back in - the built-in store cannot reuse the previous credential store.
  3. Connect LocalDevVPN, open My Apps, and tap Refresh All.
  4. Quit SideStore and return to LiveContainer.
  5. In LiveContainer Settings, tap Import Certificate from SideStore and confirm.
  6. The control should change to Remove Certificate. Verify with JIT-Less Mode Diagnose.
  7. Optionally follow Refresh Verification to confirm provisioning profiles look healthy.

Auto-refresh shortcuts

You can automate refreshes the same way standalone SideStore users do, except the shortcut should call LiveContainer's refresh action instead of SideStore's Refresh All Apps.

Troubleshooting certificate import

If LiveContainer reports that the certificate was not found, open SideStore Settings > Export Signing Certificate..., set a password, then import that file under LiveContainer Settings > Import Certificate. Re-run the diagnose test afterward.
