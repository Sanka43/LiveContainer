Sources

Sources are catalog links inside LiveContainer. They list apps you can install without hunting for IPA files by hand.

Add a source

  1. Open the Sources tab in LiveContainer.
  2. Tap the plus control.
  3. Paste the catalog URL and confirm.

You can also open a deep link like livecontainer://source?url=<encoded_source_url>. That jumps to Sources and tries to add the catalog.

Refresh and remove

  • Refresh one source, or use Refresh All to update listings.
  • Remove a source from its menu or with a swipe.

Install from a source

  1. Expand a source to see its apps.
  2. Tap Install on the app you want.
  3. LiveContainer moves to Apps and downloads the latest IPA URL from that listing.

Large catalogs (about 50+ apps) are easier to browse with search.

Common problems

  • Invalid URL - the link is wrong or not a LiveContainer-compatible source.
  • Duplicate source - that catalog is already added.
  • Unable to refresh - network issue or the source host is down.
  • No apps available - the catalog returned an empty list.
