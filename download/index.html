Use official builds only

Only download LiveContainer from the links on this page. Closed third-party builds can read everything inside your containers, including passwords and tokens.

Which package?

LiveContainer Standalone. Pick this if you already use AltStore or SideStore.
LiveContainer + SideStore Both in one free app slot. Pick this if you want a single install.
Stable vs Nightly Stable is better for daily use. Nightly is newer and may change faster.

Do not use these installers

These tools are not supported and often break entitlements:

  • Sideloadly
  • i4 / 3u Tools
  • NB Tool
  • Most online signing websites
