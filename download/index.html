Download

Use official builds only

Only download LiveContainer from the links on this page. Closed third-party builds can read everything inside your containers, including passwords and tokens.

Pick a package, download the IPA, then follow the Installation guide.

Which package?

  • LiveContainer (standalone) - if you already use AltStore or SideStore.
  • LiveContainer + SideStore - if you want both in one free app slot.

Stable is better for daily use. Nightly is newer and may change faster.

After you download

  1. Install the IPA with AltStore, SideStore, Impactor, or iloader (see Installation).
  2. Import your signing certificate.
  3. Run JIT-Less Mode Diagnose until the test passes.
Go to Installation

Do not use these installers

These tools are not supported and often break entitlements:

  • Sideloadly
  • i4 / 3u Tools
  • NB Tool
  • Most online signing websites
