Tweaks

LiveContainer can load tweaks into apps you run inside it. A small loader (TweakLoader) is injected when apps are prepared, then it loads Ellekit and your tweak files.

What you can load

  • .dylib files
  • .framework bundles (need a valid Info.plist and executable name)

Where tweaks live

  • Global Tweaks folder - applies to every guest app.
  • App-specific folder - only for apps you assign that folder to.

Load order is roughly: Ellekit / CydiaSubstrate compatibility layer, then global tweaks, then the app folder.

Assign tweaks to an app

  1. Use the primary (blue) LiveContainer and a private app when managing tweak folders.
  2. On the Tweaks tab, create or import a folder.
  3. Open the app settings and choose that folder under Tweak Folder.
  4. For shared apps, convert to private, assign the folder, then convert back if needed.

Signing

LiveContainer can resign tweaks automatically before launch when signatures look outdated. You can also tap Sign on the Tweaks tab.

If tweaks do not load

  • Confirm the folder is assigned and TweakLoader is not disabled in app settings.
  • Check Don't Inject TweakLoader / Don't Load TweakLoader - both on means no tweaks run.
  • Resign the tweaks manually.
  • Some tweaks work better with direct injection instead of the loader.
