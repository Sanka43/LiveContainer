FAQ

Short answers first. For long step lists, open the linked guide.

What is LiveContainer?

An app launcher for iPhone and iPad. You run other apps inside it instead of installing each one on the Home Screen. It is not a jailbreak and not an emulator. See the home page for a simple overview.

Where do I download it?

Only from official GitHub Releases. Start at Download.

Install or signing failed

  • Use AltStore 2.2.1+ / SideStore 0.6.2+ (or Impactor / current iloader for the SideStore bundle).
  • Keep all extensions during install.
  • Import the certificate, then run JIT-Less Mode Diagnose.

Installing LiveContainer FAQ · JIT-Less diagnose

Apps crash or will not open

  • Match LiveContainer version to your iOS version (see crash FAQ).
  • mremap_encrypted() => -1 usually means the IPA is not decrypted.
  • Try sideloading the same IPA outside LiveContainer - if it fails there too, the IPA is the problem.

App crashes FAQ

App missing in LC2 / LC3

Convert it to a Shared App on the primary LiveContainer first.
